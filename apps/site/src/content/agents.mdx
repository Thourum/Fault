## For AI agents

fault ships three agent skills: short, example-dense instructions that teach a coding agent (Claude Code, Cursor, Codex and others) how to write and migrate code with this library. They live in [`skills/`](https://github.com/Thourum/Fault/tree/main/skills) and follow the open `SKILL.md` format, so one command installs them into whichever agent you use.

```sh
npx skills add Thourum/Fault
```

Pick a single skill with `--skill`:

```sh
npx skills add Thourum/Fault --skill fault-error-handling
```

| Skill | Use when |
|---|---|
| `fault-error-handling` | Writing new functions: signatures, tags, chaining, where to capture. |
| `fault-from-try-catch` | Migrating throwing code and `try`/`catch` to `Result` and `ResultAsync`. |
| `fault-from-neverthrow` | Moving a codebase from `neverthrow` to fault. |
