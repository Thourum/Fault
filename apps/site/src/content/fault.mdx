## Fault

`Fault` is an `Error` with a tag, developer details, metadata, causes, HTTP status mapping, and an optional capture hook.

### new Fault

`new Fault(initial: Error | string | Fault): Fault`

```ts
const fault = new Fault(new Error('stripe declined'))
```

A new fault keeps the input message and cause, records its construction location, and starts with the `UNKNOWN_ERROR` tag.

### Fault.from

`Fault.from(initial: Error | string): Fault`

```ts
const fault = Fault.from(new Error('connection reset'))
  .withTag('CONNECTION_ERROR')
```

Use `Fault.from` when converting an error or message without calling the constructor directly.

### withTag

`withTag(tag: FaultTag): this`

```ts
const fault = new Fault('user missing')
  .withTag('NOT_FOUND')
```

`withTag` replaces the classification and returns the same fault for chaining.

### withDetails

`withDetails(details: string): this`

```ts
const fault = new Fault('payment failed')
  .withDetails('card_declined: insufficient_funds')
```

`withDetails` stores developer-facing context without changing the user-facing message.

### withDescription

`withDescription(details: string, message?: string): this`

```ts
const fault = new Fault('database timeout').withDescription(
  'PostgreSQL connection timed out after 5 seconds',
  'Service temporarily unavailable',
)
```

`withDescription` stores developer details and replaces the message only when the optional message is provided.

### withMetadata

`withMetadata(key: string, value: unknown): this` / `withMetadata(data: Record<string, unknown>): this`

```ts
const fault = new Fault('stripe declined')
  .withMetadata('intentId', 'pi_3Q…')
  .withMetadata({ amountCents: 4900, currency: 'eur' })
```

Both overloads merge metadata into the fault and return the same instance.

### withContext

`withContext(data: Record<string, unknown>): this`

```ts
const fault = new Fault('database unavailable').withContext({
  attemptCount: 3,
  operation: 'CREATE_PAYMENT',
})
```

`withContext` is the object-form metadata merger used by `withMetadata`.

### withCause

`withCause(cause: unknown): this`

```ts
const fault = new Fault('payment failed')
  .withCause(new Error('socket closed'))
```

`withCause` attaches any thrown value as the standard `Error.cause` and returns the same fault.

### tag

`get tag(): FaultTag | undefined`

```ts
const tag = new Fault('missing').withTag('NOT_FOUND').tag
```

`tag` returns the current classification; every newly constructed fault starts as `UNKNOWN_ERROR`.

### details

`get details(): string | undefined`

```ts
const details = new Fault('invalid input')
  .withDetails('email is not RFC 5322 compliant')
  .details
```

`details` returns the developer-facing description when one has been set.

### location

`get location(): string | undefined`

```ts
const location = new Fault('failed').location
```

`location` is the stack location captured when the fault was constructed, when available.

### metadata

`get metadata(): Record<string, unknown>`

```ts
const metadata = new Fault('failed')
  .withMetadata({ requestId: 'req_123' })
  .metadata
```

`metadata` returns a shallow copy so changing the returned object does not change the fault.

### statusCode

`get statusCode(): number`

```ts
const status = new Fault('missing')
  .withTag('NOT_FOUND')
  .statusCode
```

| Tag | Status |
| --- | ---: |
| `VALIDATION_ERROR`, `BAD_REQUEST`, `FOREIGN_KEY_ERROR` | 400 |
| `AUTHENTICATION_ERROR`, `UNAUTHORIZED` | 401 |
| `PAYMENT_FAILED` | 402 |
| `AUTHORIZATION_ERROR`, `FORBIDDEN` | 403 |
| `NOT_FOUND` | 404 |
| `CONFLICT`, `UNIQUE_CONSTRAINT_ERROR` | 409 |
| `RATE_LIMITED` | 429 |
| `NETWORK_ERROR`, `CONNECTION_ERROR` | 503 |
| `EXTERNAL_ERROR` | 502 |
| `PARSE_ERROR`, `HTTP_ERROR` | `metadata.httpStatus` or 500 |
| `DATABASE_ERROR`, `INTERNAL_ERROR`, `UNKNOWN_ERROR`, and every other tag | 500 |

`statusCode` follows this mapping and defaults unlisted or custom tags to 500.

### toJSON

`toJSON(): Record<string, unknown>`

```json
{
  "name": "Error",
  "message": "stripe declined",
  "details": "card_declined: insufficient_funds",
  "tag": "PAYMENT_FAILED",
  "statusCode": 402,
  "location": "at /Users/samuelasvanyi/.superset/worktrees/58901984-4162-408e-b6b6-d7144964da65/marble-flare/packages/fault/[eval]:1:48",
  "metadata": {
    "intentId": "pi_3Q…",
    "amountCents": 4900
  },
  "cause": {
    "name": "Error",
    "message": "boom",
    "stack": "Error: boom\n    at /Users/samuelasvanyi/.superset/worktrees/58901984-4162-408e-b6b6-d7144964da65/marble-flare/packages/fault/[eval]:1:212"
  },
  "stack": "Error: stripe declined\n    at /Users/samuelasvanyi/.superset/worktrees/58901984-4162-408e-b6b6-d7144964da65/marble-flare/packages/fault/[eval]:1:48"
}
```

`toJSON` emits structured fields for logging, serializes `Error` causes, and recursively serializes a cause that is another `Fault`; redact sensitive details, metadata, and non-Error causes before logging.

### getCauseChain

`getCauseChain(): Array<Error | unknown>`

```ts
const root = new Error('socket closed')
const chain = new Fault('payment failed')
  .withCause(root)
  .getCauseChain()
```

`getCauseChain` returns this fault followed by each `Error` cause and any final truthy non-Error cause.

### capture / Fault.onCapture

`capture(): this` / `Fault.onCapture: ((fault: Fault) => void) | undefined`

```ts
Fault.onCapture = (fault) => Sentry.captureException(fault, {
  extra: fault.toJSON(),
})

new Fault('payment failed').capture()
```

`capture` invokes the current hook when configured and always returns the same fault unchanged.

### ServiceError

`ServiceError(tag: FaultTag, message: string, description?: string): Fault`

```ts
const fault = ServiceError(
  'NOT_FOUND',
  'User not found',
  'No user matched usr_123',
)
```

`ServiceError` creates a tagged fault whose details are the description or, when omitted, the message.

### FaultTag

`FaultTag` includes the predefined groups from the source and accepts custom string tags.

```ts
type FaultTag =
  // Auth
  | 'AUTHENTICATION_ERROR'
  | 'AUTHORIZATION_ERROR'
  // Resource
  | 'NOT_FOUND'
  | 'DATABASE_ERROR'
  // Network/API
  | 'NETWORK_ERROR'
  | 'PARSE_ERROR'
  | 'HTTP_ERROR'
  // Data
  | 'VALIDATION_ERROR'
  | 'BAD_REQUEST'
  | 'UNAUTHORIZED'
  | 'FORBIDDEN'
  | 'CONFLICT'
  | 'RATE_LIMITED'
  | 'PAYMENT_FAILED'
  | 'EXTERNAL_ERROR'
  | 'CONFIGURATION_ERROR'
  | 'CONNECTION_ERROR'
  | 'UNIQUE_CONSTRAINT_ERROR'
  | 'FOREIGN_KEY_ERROR'
  | 'TRANSACTION_ROLLBACK_ERROR'
  // Catch-all
  | 'INTERNAL_ERROR'
  | 'UNKNOWN_ERROR'
  // Custom
  | (string & {})
```

Use a predefined tag when it fits; `string & {}` keeps autocomplete while allowing domain-specific tags.
