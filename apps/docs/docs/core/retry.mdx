# retry

retry repeats a ResultAsync operation while it returns Err and the optional predicate permits another attempt.

## retry

`retry<T, E>(fn: () => ResultAsync<T, E>, opts: { times: number, delayMs?: number, when?: (error: E) => boolean }): ResultAsync<T, E>`

```ts
const user = retry(
  () => safeDb(db.query.users.findFirst({
    where: eq(users.id, userId),
  })),
  {
    times: 3,
    delayMs: 200,
    when: (fault) => fault.tag === 'CONNECTION_ERROR',
  },
)
```

The first attempt always runs, even when `times` is 0 or negative; set `times` to at least 1 because it represents the total attempts. `delayMs` is a fixed delay between attempts and defaults to 0, and `when` defaults to retrying every `Err`.

The returned `ResultAsync` resolves to the first `Ok`, the `Err` rejected by `when`, or the last `Err` after all attempts.

`fn` must return a `ResultAsync` without throwing synchronously; wrap a throwable async function with `ResultAsync.fromThrowable` first.

```ts
const loadUser = ResultAsync.fromThrowable(
  async () => client.users.get(userId),
  (error) => Fault.from(error as Error).withTag('CONNECTION_ERROR'),
)

const user = retry(loadUser, { times: 3 })
```
